# Skills

Each subdirectory is a domain; each skill is a folder containing `SKILL.md`.

```
skills/
├── discovery/     8 skills — before product/market fit
├── strategy/      9 skills — what game you are playing
├── gtm/          13 skills — demand, launch, price
├── revenue/       6 skills — enterprise sales execution
├── operations/    5 skills — running the company
└── brand/         4 skills — positioning and communication
```

Skills are self-contained. Copying a single folder into your agent's skills directory
works; the only thing you lose is the cross-links in each file's **Pairs with** section.

For the full index with descriptions and lineage, see the [root README](../README.md).
